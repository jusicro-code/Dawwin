# وفّر — مقارنة أسعار السوبرماركت 🛒

تطبيق جوال بسيط (Expo + Supabase) يقارن أسعار المنتجات بين: كيو، الدانوب، بنده، العثيم، التميمي.

## المميزات
- هيدر إعلانات بأعلى الصفحة (يتقلب تلقائياً، ويُدار من جدول `ads`)
- بحث وتصنيفات، وكل منتج يعرض أرخص سعر ووين
- صفحة المنتج: السعر في كل متجر من الأرخص للأغلى
- سلّتي: يحسب إجمالي سلتك في كل متجر ويقولك الأرخص وكم توفّر

## التشغيل على Expo Go
```bash
cd waffir
npm install
npx expo start --tunnel
```
امسح الـ QR من تطبيق Expo Go.

## Supabase
1. شغّل `supabase/schema.sql` ثم `supabase/seed.sql` في SQL Editor.
2. انسخ `.env.example` إلى `.env` وحط الرابط والمفتاح.
بدون `.env` التطبيق يشتغل على بيانات تجريبية داخلية.

> الأسعار الموجودة حالياً تجريبية للعرض فقط.
